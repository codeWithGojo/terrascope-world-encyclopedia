# TerraScope logo

The orbital T combines the TerraScope initial with a compass-like pointer and a sea-teal orbit on a deep navy tile. The original has a transparent background outside the tile. Header, footer and browser icons use the same artwork.

Created with the built-in ImageGen tool. Only transparent margin normalization, resizing and format export were used for the website variants.

## Files

- `public/brand/terrascope-logo.png` — original generated logo.
- `public/brand/terrascope-mark.webp` — compact header/footer mark.
- `public/favicon.ico` — 16, 32, 48 and 64 pixel frames.
- `public/icons/favicon-16.png` and `public/icons/favicon-32.png` — browser icons.
- `public/icons/apple-touch-icon.png` — 180 pixel touch icon.
- `public/icons/icon-192.png` and `public/icons/icon-512.png` — larger application icons.

## Generation prompt

Use case: logo-brand. Asset type: production logo icon and favicon for TerraScope, a world exploration and travel website. Create one beautiful, original, minimal geometric symbol: a confident uppercase T integrated with a sweeping planetary orbit and a subtle compass pointer. Deep navy rounded-square tile (#0B1B2A), vivid sea teal (#72D9C2), tiny icy-white highlights. Bold T silhouette in the centre, one clean orbital arc moving from lower left to upper right with a small pointed end suggesting exploration. Balanced, memorable, precise vector-like edges; premium restrained design. Slight facet lighting to harmonize with a glass interface, but essentially flat and sharply readable. Icon occupies nearly the full square with only 5 percent clear space around the tile. Thick shapes and generous negative space so it remains legible at 16 by 16 pixels. Genuine transparency outside the rounded navy tile. No wordmark, no text other than the abstract T shape, no extra symbols, no mockup, no outer shadow, no complex grid lines, no watermark. Single centred icon only.
